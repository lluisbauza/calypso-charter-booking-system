# Project Calipso

Boat Charter Booking System developed in Java, Swing and MySQL.

## Features

- User management
- Reservation management
- Client management
- Agency management

## Technologies and Tools

- Java
- IntelliJ IDEA
- Swing
- MySQL + WorkBench
- JDBC
- Git
