# Project Calipso

Boat Charter Booking System developed in Java, Swing and MySQL.

## Features

- User management
- Reservation management
- Client management
- Agency management

## Technologies and Tools

- Java
- IntelliJ IDEA
- Swing
- MySQL + WorkBench
- JDBC
- Git

## Current Status

- Database design completed
- Initial schema created

## Run the app
1. Run schema.sql
2. Run sample_data.sql
3. ...Launch the application
