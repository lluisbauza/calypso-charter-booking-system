## About the Project

Calypso is a boat charter booking system built with Spring Boot.

The application is designed to manage boats, excursion types, available booking slots and customer reservations. Its main goal is to provide a simple booking flow where users can check available departures for a specific date and reserve a boat excursion.

The project is being developed as a practical backend application to apply concepts such as:

- Spring Boot
- Spring Data JPA
- PostgreSQL
- RESTful architecture
- Validation
- Exception handling
- Testing
- Relational data modelling
- Thymeleaf

The current version focuses on the core booking logic and data model, with the possibility of adding a frontend and authentication in later stages.
